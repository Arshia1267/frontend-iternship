## یادداشت‌های آموزشی
- DNS چیست؟ مانند دفترچه تلفن اینترنت عمل می‌کند و دومین‌ها را به IP تبدیل می‌کند.
- Git چیست؟ سیستم کنترل نسخه‌ای که تغییرات کد را ثبت و مدیریت می‌کند.
- هدف هفته اول: تسلط کامل روی دستورات اولیه گیت مثل init, add, commit, log و push.
- وضعیت تمرین: تمرین با موفقیت انجام شد و آماده ارسال به گیت‌هاب است.
