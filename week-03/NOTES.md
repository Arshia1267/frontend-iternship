# HTML Forms

 ## Form

تگ "form" برای ایجاد فرم و دریافت اطلاعات از کاربر استفاده می‌شود. ورودی‌ها و اجزای مرتبط با فرم داخل آن قرار می‌گیرند.

## Input

تگ "input" برای دریافت اطلاعات از کاربر استفاده می‌شود. ویژگی "type" نوع ورودی را مشخص می‌کند.

- "text": دریافت متن معمولی.
- "email": دریافت ایمیل و بررسی اولیه فرمت آن توسط مرورگر.
- "password": دریافت رمز عبور و مخفی کردن کاراکترهای آن.
- "number": دریافت مقدار عددی.
- "checkbox": انتخاب چند گزینه به‌صورت مستقل.
- "radio": انتخاب یک گزینه از بین چند گزینه با "name" یکسان.
- "date": انتخاب تاریخ.
- "tel": دریافت شماره تلفن.

## Label

تگ "label" برای مشخص کردن عنوان ورودی استفاده می‌شود. با استفاده از "for" در Label و "id" در Input آن‌ها را به هم متصل می‌کنیم.

## ID و Name

- "id": شناسه منحصربه‌فرد هر عنصر در صفحه.
- "name": نام فیلد که برای شناسایی اطلاعات هنگام ارسال فرم استفاده می‌شود.

## Required

ویژگی "required" برای اجباری کردن پر کردن یک فیلد استفاده می‌شود و مرورگر هنگام ارسال فرم، خالی بودن آن را بررسی می‌کند.

## Button

تگ "button" برای ایجاد دکمه استفاده می‌شود.

- "button": دکمه معمولی.
- "submit": ارسال فرم.
- "reset": بازگرداندن ورودی‌ها به حالت اولیه.


# خلاصه معانی تگ ها
Form: برای ایجاد فرم و جمع‌آوری اطلاعات کاربر استفاده می‌شود.

Input: انواع داده‌ها مانند متن، ایمیل، عدد و رمز عبور را دریافت می‌کند.

Label: عنوان فیلد است و با ویژگی‌های for و id به ورودی مرتبط می‌شود.

Placeholder: متن راهنمای داخل فیلد است و جایگزین Label نیست.

Name: مشخص می‌کند مقدار ورودی با چه نامی در اطلاعات فرم ارسال شود. بدون Name، مقدار آن ورودی معمولاً ارسال نمی‌شود.

Required: فیلد را اجباری می‌کند و مرورگر هنگام ارسال، خالی بودن آن را بررسی می‌کند.

Minlength: حداقل تعداد کاراکترهای مجاز را تعیین می‌کند.

Maxlength: حداکثر تعداد کاراکترهای مجاز را تعیین می‌کند.

Select: یک فهرست انتخاب ایجاد می‌کند.

Option: هر گزینه داخل Select را مشخص می‌کند.

Optgroup: گزینه‌ها را به کمک ویژگی label دسته‌بندی می‌کند.

Textarea: برای متن‌های چندخطی است و با rows و cols اندازه اولیه آن مشخص می‌شود.

Submit: فرم را ارسال می‌کند و اعتبارسنجی معمول مرورگر را اجرا می‌کند.

Reset: فرم را به مقادیر اولیه بازمی‌گرداند.

Button: دکمه معمولی است و بدون کدنویسی اضافی عملکرد خاصی ندارد.

Button در مقایسه با Input Submit: هر دو می‌توانند فرم را ارسال کنند، اما Button در محتوای داخلی انعطاف بیشتری دارد.

Form Validation: مرورگر می‌تواند بعضی خطاهای ورودی را تشخیص دهد؛ بااین‌حال اعتبارسنجی سمت سرور نیز برای برنامه‌های واقعی ضروری است.

## منابع

## مطالبی که یاد گرفتم

۱. Accessibility

دسترس‌پذیری یعنی طراحی صفحات وب به شکلی که همه افراد، از جمله افراد نابینا و کسانی که فقط از کیبورد استفاده می‌کنند، بتوانند از سایت استفاده کنند.

۲. Alternative Text (alt)

ویژگی alt برای توضیح محتوای تصاویر استفاده می‌شود. متن جایگزین باید کوتاه، دقیق و معنادار باشد.

اگر تصویر فقط جنبه تزئینی داشته باشد، باید مقدار alt را خالی قرار دهیم (alt="").

اگر تصویر به‌عنوان لینک استفاده شود، متن alt باید مقصد یا کاربرد لینک را مشخص کند.

۳. Label

تگ label به کاربران، مخصوصاً کسانی که از screen reader استفاده می‌کنند، کمک می‌کند تا کاربرد هر input را متوجه شوند.

مقدار for در label باید با مقدار id در input یکسان باشد. همچنین placeholder جایگزین label نیست.

۴. Headings

تیترها باید ترتیب منطقی داشته باشند. ابتدا از h1، سپس از h2 و برای زیربخش‌های آن از h3 استفاده می‌کنیم.

نباید برای تغییر اندازه نوشته‌ها از تیترهای مختلف استفاده کنیم، زیرا وظیفه تیترها مشخص کردن ساختار صفحه است. برای تغییر ظاهر نوشته‌ها باید از CSS استفاده کنیم.

۵. تفاوت button و a

تگ button برای انجام یک عمل مانند ارسال فرم استفاده می‌شود.

تگ a برای انتقال کاربر به یک صفحه، آدرس یا فایل دیگر استفاده می‌شود.

۶. متن لینک‌ها

متن لینک باید معنادار باشد تا کاربر قبل از کلیک کردن متوجه شود که لینک او را به چه مقصدی هدایت می‌کند.
